# d2pfx-arcana-fixes
The base models of arcanas and personas, rebuilt so they work as the hero's own look, for Dota 2 Mod Manager.

Each folder under `src/` holds one base: the hero's models and the materials those models use, nothing else. Particles, sounds, ability icons and portraits come from the game itself, through `items_game.txt`, when the app puts the item on.

for details: https://github.com/dota2modmanager/dota2-mod-manager
